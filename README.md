# ByAzen

Персональный игровой лаунчер для Windows x64 на Electron, HTML, CSS и JavaScript. Приложение открывается развёрнутым; библиотека, источники, очередь и оформление хранятся локально. На главной доступна редакционная подборка — это не текущий рейтинг Steam.

## Новое в 1.0.26 — 100 из 100 пунктов

- **Оформление:** локальный MP4/WebM до 80 МБ и 20 минут, без звука. Видеофон ставится на паузу при сворачивании и выключается при уменьшенном движении. Галерея хранит до 12 пакетов ByAzen JSON; импорт не запускает код, не принимает сетевые ресурсы и не применяет тему автоматически.
- **Библиотека:** импорт из Epic (нужны манифесты `.item`), GOG (`goggame-*.info`) и itch.io (локальная папка `.itch`). Для игр без метаданных есть общий поиск EXE. Перетащите EXE или LNK и подтвердите импорт. Обложки Steam нужно подтвердить вручную. Ярлык на рабочем столе открывает ByAzen с подтверждением игры и выбранного профиля запуска.
- **Загрузки:** при добавлении magnet выберите «Выбрать файлы» и дождитесь метаданных. В папку назначения попадут только отмеченные файлы; на границах частей могут передаваться байты соседних файлов.
- **Настройки:** «Проверить обновление» обращается к [официальному релизу GitHub](https://github.com/gggvkvh405-rgb/1/releases/latest). Скачанный EXE можно сверить по размеру и SHA-256; автоматической установки нет. Перед переходом к релизу и при первом запуске после смены версии ByAzen сохраняет прежние настройки в `update-backups`. «Только локально» отключает сетевые функции ByAzen после перезапуска; это не сетевой фильтр для других приложений. Локальные игроки имеют собственные настройки, библиотеку и журнал. При переключении игра должна быть закрыта, а незавершённые загрузки остаются на паузе до ручного возобновления.
- **Журнал:** подбор учитывает время, настроение и режим из карточек игр. В «Игровых вечерах» можно указать игру, дату, участников и заметки и поделиться событием файлом `.ics`.

## Новое в 1.0.25 — 87 из 100 пунктов

- **Поиск и Steam:** строка поиска открывает результаты из библиотеки, настроек, Steam и источников. Запрос `"resident evil" +2 -demo` поддерживает фразы и исключения. В Steam дополнительные текстовые условия проверяются на полученной странице, без выгрузки всего каталога. Есть сохранённые фильтры, раздельный кооператив, скрытие DLC/демо, карточки с медиа, сравнение до четырёх игр и желаемое с заметками. Календарь использует даты из желаемого и позволяет перейти к предстоящим релизам Steam. Нет точной даты — ByAzen её не придумывает.
- **Уведомления о скидках:** задайте порог в карточке Steam. Приложение проверяет сохранённый регион и валюту небольшими порциями, пока открыто, и записывает уведомление, если есть скидка и цена не выше порога. Это не мгновенный мониторинг; цены и медиа могут быть недоступны в отдельных регионах. В веб-предпросмотре нет фоновой проверки цен.
- **Источники:** до пяти URL за один предпросмотр, группировка версий без отключения общего списка записей, ручные связи названий, приоритет в окне загрузки, закладки версий, отслеживание игр. В настройках списка: до 20 событий истории, сравнение двух последних загруженных версий с примерами изменений, экспорт кэша Hydra JSON и интервал автообновления. По умолчанию автоматически обновляются предустановленные URL, пока приложение открыто. Кэш JSON содержит ссылки самого списка; экспорт коллекции HTML, наоборот, ссылок не содержит.
- **Файлы:** отчёт по размеру выбранной папки, проверка .exe и обязательных файлов по относительным путям, копии сохранений в выбранную папку, перенос карточек и настроек через JSON без .exe, путей или профилей запуска. Очистка удаляет только отмеченные, неизменившиеся временные части известных завершённых/отменённых HTTP-задач; не удаляет игры, торренты и активные части. Синхронизация с облаком не выполняется ByAzen: для неё можно выбрать папку, которую уже синхронизирует отдельная программа.
- **Главная и состояние:** выбирайте и переставляйте виджеты, экспортируйте коллекцию как статичный HTML. «Центр состояния» показывает последнюю проверку Steam, состояние хранилища и списков. Классический режим включается в настройках или запуском с `--safe-mode`; он не перезаписывает тему. Опция экономии эффектов реагирует на батарею и запущенный ByAzen процесс `.exe`; Steam-процессы не отслеживаются.

## Запуск из исходников

Требуется Windows 10/11 x64 и Node.js 22 LTS с npm. В PowerShell из папки репозитория:

```powershell
npm ci
npm test
npm start
```

Для браузерного предпросмотра интерфейса (в том числе на Linux) выполните `npm ci --ignore-scripts`, затем `npm run dev` и откройте `http://localhost:4173`. Предпросмотр хранит данные в localStorage, не может запускать `.exe` или управлять локальными загрузками. URL-импорт в нём зависит от CORS, а обновление локального JSON требует повторного импорта. Код Electron этих ограничений браузерного режима не имеет.

## Портативная сборка Windows x64

```powershell
npm ci
npm test
npm run build:win
```

Откройте `release/ByAzen-1.0.26-win-x64-portable.exe`. Установка и права администратора не требуются. Сборка не подписана: Windows может показать предупреждение SmartScreen. Используйте только сборку из доверенного источника или соберите её самостоятельно. Поместите `.exe` в доступную для записи папку: папка `ByAzen-data` создаётся рядом с ним и её можно переносить вместе с лаунчером. Абсолютные пути к установленным играм и к загружаемым файлам после переноса могут потребовать обновления.

Workflow **Windows portable** собирает `.exe` на Windows, проверяет, что появилось окно Electron, и публикует файл в разделе **Artifacts** соответствующего запуска GitHub Actions. Команда сборки требует доступа к ресурсам загрузки Electron и electron-builder.

Переходы разделов, появление карточек, диалоги, темы и прогресс загрузок анимированы. Опция **«Уменьшить движение»** в настройках отключает эффекты; системное предпочтение учитывается независимо от неё.

## Загрузки и диагностика

В **«Загрузках»** видны скорость, примерное время и последние замеры. Для BitTorrent показываются подключённые участники и ответы поддерживаемых трекеров. **«Проверить скачивание»** загружает фиксированный публичный HTTPS-файл размером около 15 КБ в выбранную папку, сверяет SHA-256 и удаляет временные данные. Этот тест не подтверждает доступность конкретной раздачи. У ошибок есть кнопка копирования отчёта без названий игр, ссылок, путей и IP-адресов.

**«Настройки очереди»**: от 1 до 4 одновременных задач, раздельные лимиты скачивания и отдачи на задачу и ежедневное расписание по местному времени. Лимит скорости применяется при следующем старте задачи. Расписание действует, пока лаунчер открыт: вне окна передача останавливается без удаления временных данных; сервер без поддержки возобновления может начать файл заново. После перезапуска незаконченные задачи остаются на ручной паузе. **«В начало»** меняет приоритет ожидающей задачи, не прерывая текущую. При известном размере проверяется доступное место, включая временную копию BitTorrent. В ручном добавлении HTTP(S) можно указать SHA-256 от издателя; при несовпадении файл не сохраняется в папке назначения.

## Установленные игры и копии сохранений

**Библиотека → Найти установленные** просматривает выбранную папку и до четырёх уровней подпапок. Это кандидаты на импорт, а не гарантия, что каждый `.exe` — игра. Отметьте нужные файлы и подтвердите импорт. **Импорт Steam** читает установленные записи из выбранной библиотеки Steam или папки `steamapps`. Эти карточки запускаются через уже установленный Steam. Поиск ничего не запускает и не импортирует без подтверждения. Поиск ограничен 5 000 просмотренных элементов и 120 результатами за раз; для большой библиотеки выбирайте более узкую папку.

В карточке игры **«Папки»** привязывает папки сохранений, модов и скриншотов. **«Копии»** создаёт ручные резервные копии и позволяет включить копирование перед запуском из ByAzen. В случае ошибки автоматической копии запуск останавливается; идентичные данные не копируются повторно. Закройте игру перед копированием и восстановлением. ByAzen хранит до 10 снимков на игру в `ByAzen-data/save-backups`. Папка сохраняемых файлов ограничена 512 МБ и 2 000 файлами и не должна содержать символических ссылок. Восстановление сначала показывает добавления и замены, проверяет, что файлы не изменились, и делает отдельную защитную копию. Оно не удаляет файлы, отсутствующие в снимке. Для защитной копии нужно оставить свободное место и один слот в истории.

## Галерея тем

**Настройки → Темы**: 110 фонов в 14 коллекциях — 100 локальных SVG-фонов и 10 оригинальных сцен в стилях аниме, кино, художественной фотографии и фэнтези. Сцены входят в сборку и не являются кадрами из конкретных фильмов. Есть поиск, фильтры, случайный выбор, предпросмотр, а также тёмная, светлая и OLED-темы. Настройка **«Уменьшить движение»** и соответствующая системная настройка отключают эффекты, не скрывая фон. SVG-фоны можно заново создать командой `npm run themes:art`. **«Редактор темы»** применяет выбранные цвет акцента, непрозрачность панелей, скругление и шрифт поверх текущей темы. Интенсивность атмосферного слоя настраивается независимо; при 0 фон остаётся без слоя эффектов.

**«Свой фон»** принимает локальный JPG, PNG или WebP до 16 МБ (до 28 мегапикселей и 12 000 пикселей по стороне). Изображение сохраняется в профиле приложения после применения; ничего не загружается в интернет. Режим **«Заполнить»** обрезает края по размеру окна, **«Вписать»** показывает файл целиком. Кнопка **«Вернуть фон темы»** отключает своё изображение, сохраняя его на будущее; полностью удалить копию можно в диалоге **«Свой фон»**. Цветовая палитра по-прежнему задаётся выбранной темой.

## Возможности и ограничения

- **Steam.** Постраничный публичный поиск Steam Store, по 24 товара за запрос (до 500 страниц). Фильтры отправляются в магазин: тип, метка, ОС, ценовой порог, скидки, сортировка и регион. Ценовые пороги интерпретирует Steam; местную цену и валюту лаунчер отображает только из ответа магазина. Региональный фильтр не меняет аккаунт Steam. Результаты выводятся списком с фильтрами справа. Жанры и теги передаются в Steam; диапазон года выпуска и подключённые источники уточняют уже загруженную страницу. Если Steam недоступен, показывается помеченная локальная подборка из 12 игр и приложений с официальными ссылками, но без актуальных цен и данных о наличии. Каталог зависит от неверсированного публичного интерфейса магазина.
- **Источники.** Импорт по HTTP(S) или из локального JSON, предпросмотр, включение, обновление и удаление. В «Источниках» вставьте прямой URL JSON, нажмите «Предпросмотр» и подтвердите импорт. Быстрый переход есть в фильтре «Источники загрузки» каталога. Регистрация или аккаунт не нужны. По умолчанию источников нет. Совпадения на главной определяются по нормализованному названию и означают только наличие записи в активном источнике, а не проверку файла или списка раздач. Безопасность и законность использования источника остаются ответственностью пользователя. Пример структуры (пустой список, без внешних ссылок):

  ```json
  { "name": "Мои разрешённые загрузки", "downloads": [] }
  ```

  Основной OnlineFix — уже заданный список `hydrasources.su`: он обновляется в начале очереди и показывается первым среди совпадений в окне загрузки, если пользователь не выбрал другой список. Если он был отключён или удалён, кнопка **Источники → Подключить OnlineFix** включает или возвращает его без дубликатов. Получение списка не означает доступность отдельных раздач.

  Каждая запись `downloads` содержит `title` и массив `uris`; `fileSize` и `uploadDate` необязательны. Лимиты ручного импорта: 4 МБ на JSON, 10 000 записей, 20 собственных источников. В настольной версии 18 предоставленных пользователем ссылок добавляются один раз и включаются по умолчанию. Существующие настройки не меняются; отключение или удаление сохраняется. Списки обновляются в фоне при запуске (не чаще раза в сутки после успешного обновления), с лимитом 24 МБ и 50 000 записей на предустановленный источник (для Xatab — 64 МБ и 125 000 записей). На один домен одновременно отправляется один запрос списка; после временной сетевой ошибки ByAzen делает одну повторную попытку, а HTTP 403, 404 и 429 не повторяет автоматически в рамках одного запроса. Команда **«Повторить загрузку списков»** обновляет неудачно загруженные включённые предустановленные списки и сохраняет кеш при ошибках. Через минуту после стартового обновления временно недоступные подключённые списки проверяются ещё раз; HTTP 403 и 404 не участвуют в этом отложенном повторе. В карточке источника **«Заменить список»** можно проверить новый URL или локальный Hydra JSON и подтвердить замену. Если список не прочитан, пуст или уже подключён по этой ссылке, прежние данные сохраняются. Состояние «Включён» или «Отключён» сохраняется при успешной замене. Рядом с источником видны статус и ошибки; ошибки обновления не стирают сохранённый список. В Windows в разделе **«Источники»** команда **«Проверить все источники»** отдельно перечитывает каждый подключённый список, включая отключённые и локальные, и показывает количество исходных, пропущенных и доступных в поиске записей. Она не меняет кеш или настройки, не открывает игровые ссылки и не проверяет соответствие каждой записи каталогу Steam. Добавление списка не запускает загрузку игры. Нажатие на игру на главной, в каталоге или в поиске по источникам открывает окно загрузки ByAzen. В нём можно выбрать источник, версию и способ загрузки. Если совпадений нет, окно показывает подсказку и позволяет повторить поиск; браузер не открывается. Прямые HTTP(S)-ссылки и magnet отправляются во встроенную очередь. Magnet использует DHT, публичные UDP-трекеры с IPv4 и указанные в ссылке публичные числовые адреса участников. Если метаданные не получены, очередь различает отсутствие подключений и подключение без метаданных; можно повторить попытку или выбрать другую раздачу. Если после получения метаданных и проверки локальных частей в течение 3 минут не поступают данные, очередь освобождает место для следующей задачи, а скачанные части остаются для повтора. Если прямая ссылка игры вместо файла возвращает HTML-страницу, загрузка отмечается ошибкой, а не как завершённая. При сравнении названий ByAzen учитывает метки релиза вроде `[Repack]` и `Free Download`, версии (в том числе `1.0.10` в конце названия), сборки, некоторые издания и двуязычные названия. Отдельные DLC, подзаголовки и разные номера частей не объединяются. Для некоторых игр распознаются локализованные названия и сокращения. Записи с похожим названием или опечаткой могут появиться отдельно в блоке **«Похожие записи»**: проверьте полное название перед выбором. Подсказки не добавляют загрузку автоматически. При поиске по названию в каталоге превью совпадений из загруженных списков показывается автоматически, отдельно от Steam. Кнопка **«Искать в источниках»** открывает полный список совпадений. Для просмотра без запроса выберите **«Все игры из источников»**: доступны все записи загруженных и включённых списков, фильтр по отдельному источнику и переход к любой странице. Ручной поиск также проверяет русскую/английскую раскладку.
- **Библиотека.** Название и `.exe` выбирает пользователь. Коллекции перечисляются через запятую. В профиле запуска каждый аргумент записывается на отдельной строке и передаётся буквально (без внешних кавычек). Приложение не запускает файлы само, не импортирует аккаунт Steam и не управляет DRM.
- **Загрузки.** Одна активная задача HTTP(S) или BitTorrent, остальные в очереди. Magnet поддерживает v1 и гибридный v1/v2 через DHT и публичные UDP-трекеры; v2-only, HTTP-трекеры и веб-сиды не поддерживаются. Нужны доступные участники раздачи; пока задание активно, ByAzen может отдавать им части файла. После завершения раздача прекращается. При записи готового торрента временно требуется место и для проверенных частей, и для результирующих файлов. После перезапуска незавершённые загрузки остаются на паузе. Для возобновления HTTP сервер должен принимать `Range` и возвращать валидатор (`ETag` или `Last-Modified`); при ответе целым файлом передача идёт с начала. Частичные файлы хранятся рядом с выбранным путём. Существующие файлы не перезаписываются. Удаление позиции завершённой загрузки не удаляет сам файл.
- **Темы.** 100 вариантов (10 палитр × 10 фонов), плюс тёмная, светлая и OLED. Системный `prefers-reduced-motion` применяется всегда; движение также можно отключить вручную.

## Безопасность и проверка

Renderer работает с `contextIsolation`, sandbox и без `nodeIntegration`. Привилегированные операции идут через ограниченный preload; процессы игр запускаются без оболочки только по выбранному пользователем пути. Сетевые операции основного процесса проверяют протокол, каждое перенаправление и DNS-адрес (локальные и служебные адреса не разрешаются).

`npm test` проверяет валидацию Hydra JSON, соответствие источников, построение запросов и разбор ответов Steam, ограничения URL и запуска, состояния очереди, возобновление, отмену и защиту от перезаписи. Сетевые ответы в тестах локально имитируются.
