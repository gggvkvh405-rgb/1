# ByAzen

Персональный игровой лаунчер для Windows x64 на Electron, HTML, CSS и JavaScript. Приложение открывается развёрнутым; библиотека, источники, очередь и оформление хранятся локально. На главной доступна редакционная подборка — это не текущий рейтинг Steam.

## Запуск из исходников

Требуется Windows 10/11 x64 и Node.js 22 LTS с npm. В PowerShell из папки репозитория:

```powershell
npm ci
npm test
npm start
```

Для браузерного предпросмотра интерфейса (в том числе на Linux) выполните `npm ci --ignore-scripts`, затем `npm run dev` и откройте `http://localhost:4173`. Предпросмотр хранит данные в localStorage, не может запускать `.exe` или управлять локальными загрузками. URL-импорт в нём зависит от CORS, а обновление локального JSON требует повторного импорта. Код Electron этих ограничений браузерного режима не имеет.

## Портативная сборка Windows x64

```powershell
npm ci
npm test
npm run build:win
```

Откройте `release/ByAzen-1.0.4-win-x64-portable.exe`. Установка и права администратора не требуются. Сборка не подписана: Windows может показать предупреждение SmartScreen. Используйте только сборку из доверенного источника или соберите её самостоятельно. Поместите `.exe` в доступную для записи папку: папка `ByAzen-data` создаётся рядом с ним и её можно переносить вместе с лаунчером. Абсолютные пути к установленным играм и к загружаемым файлам после переноса могут потребовать обновления.

Workflow **Windows portable** собирает `.exe` на Windows, проверяет, что появилось окно Electron, и публикует файл в разделе **Artifacts** соответствующего запуска GitHub Actions. Команда сборки требует доступа к ресурсам загрузки Electron и electron-builder.

## Возможности и ограничения

- **Steam.** Постраничный публичный поиск Steam Store, по 24 товара за запрос (до 500 страниц). Фильтры отправляются в магазин: тип, метка, ОС, ценовой порог, скидки, сортировка и регион. Ценовые пороги интерпретирует Steam; местную цену и валюту лаунчер отображает только из ответа магазина. Региональный фильтр не меняет аккаунт Steam. Результаты выводятся списком с фильтрами справа. Жанры и теги передаются в Steam; диапазон года выпуска и подключённые источники уточняют уже загруженную страницу. Если Steam недоступен, показывается помеченная локальная подборка из 12 игр и приложений с официальными ссылками, но без актуальных цен и данных о наличии. Каталог зависит от неверсированного публичного интерфейса магазина.
- **Источники.** Импорт по HTTP(S) или из локального JSON, предпросмотр, включение, обновление и удаление. Регистрация или аккаунт не нужны. По умолчанию источников нет. Совпадения на главной определяются по нормализованному названию и означают только наличие записи в активном источнике, а не проверку файла или списка раздач. Безопасность и законность использования источника остаются ответственностью пользователя. Пример структуры (пустой список, без внешних ссылок):

  ```json
  { "name": "Мои разрешённые загрузки", "downloads": [] }
  ```

  Каждая запись `downloads` содержит `title` и массив `uris`; `fileSize` и `uploadDate` необязательны. Лимиты: 4 МБ на JSON, 10 000 записей, 20 источников. Magnet передаётся системному обработчику, если установлен торрент-клиент. HTTP(S)-ссылку можно открыть в браузере или добавить в очередь, если она ведёт непосредственно к файлу.
- **Библиотека.** Название и `.exe` выбирает пользователь. Коллекции перечисляются через запятую. В профиле запуска каждый аргумент записывается на отдельной строке и передаётся буквально (без внешних кавычек). Приложение не запускает файлы само, не импортирует аккаунт Steam и не управляет DRM.
- **Загрузки.** Один активный файл, остальные в очереди. После перезапуска незавершённые загрузки остаются на паузе. Для возобновления сервер должен принимать `Range` и возвращать валидатор (`ETag` или `Last-Modified`); при ответе целым файлом передача идёт с начала. Частичные файлы хранятся рядом с выбранным путём. Существующие файлы не перезаписываются. Удаление позиции завершённой загрузки не удаляет сам файл.
- **Темы.** 100 вариантов (10 палитр × 10 фонов), плюс тёмная, светлая и OLED. Системный `prefers-reduced-motion` применяется всегда; движение также можно отключить вручную.

## Безопасность и проверка

Renderer работает с `contextIsolation`, sandbox и без `nodeIntegration`. Привилегированные операции идут через ограниченный preload; процессы игр запускаются без оболочки только по выбранному пользователем пути. Сетевые операции основного процесса проверяют протокол, каждое перенаправление и DNS-адрес (локальные и служебные адреса не разрешаются).

`npm test` проверяет валидацию Hydra JSON, соответствие источников, построение запросов и разбор ответов Steam, ограничения URL и запуска, состояния очереди, возобновление, отмену и защиту от перезаписи. Сетевые ответы в тестах локально имитируются.

Обложки — материалы страниц соответствующих игр в Steam; права принадлежат их правообладателям. Баннер Cyberpunk 2077 и изображение Onimusha взяты из переданного референса; текст интерфейса и сведения об источниках отрисовываются отдельно.
